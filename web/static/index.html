02它怎么帮你

五步，一步都不替你做决定

  1. 问清楚

    你会什么、做过什么、在哪个城市、有什么走不开的事。只问必要的；问过一次就记住，除非你让它忘掉。

  2. 找得到

    在语料库和全国网上检索里同时找岗位、培训、创业扶持和补贴。每一条都带出处，带发布时间——一条本地的旧信息和一条外地的新信息，浪费的是两种不同的东西。

  3. 念条件

    把公开的门槛一条条读出来：已符合、未符合、不确定。它不替任何机构下结论——谁说了算，它会告诉你。

  4. 帮你办

    材料替你起草。真要提交的那一步，先把要发出去的原文摆给你看；你点头之前，什么都没有发生。

  5. 盯着办，或者转给人

    后续每一步都有人负责、有渠道、有先后。走不下去，它把已经写好的情况一起转给真人，你不用从头再说一遍。

03给谁用

四类人，四条不同的路

不是四个话术模板。每一类都有自己的目标、边界、可用工具、必要信息和验收标准，写在同一份注册表里——路由、权限、提示词、界面和评测都读它。

一个人 · 机会路径

你自己张罗工作、培训或补贴。记下你的技能、经历、城市和难处，匹配真实的岗位、培训、创业扶持和补贴，把公开条件念清楚，帮你起草材料，跟进后续，讲明白流程怎么走。

走常规路太贵的人 · 无障碍支持

毕业生、转岗工人、灵活就业者、农民工、照护家庭。先解决话题之前的摩擦：大白话、大字号、可朗读、用你说的那种话回你、可由窗口的人协助；永远给得出一个电话或一个带办公时间的地址；该转人的时候早点转，并且情况已经替你写好了。

窗口和社区工作人员 · 服务串联

把就业、培训、社保、医保、托育、养老、住房的流程，按人串成一份可跟踪的清单：谁负责、走哪个渠道、哪一步依赖哪一步——让居民不用再自己当各个窗口之间的「接口人」。

规划与政策 · 供需洞察

只看已授权、去标识的汇总。找出「岗位在这儿但人够不着」和「支持在那儿但没人来领」；带 k-匿名下限，每个数字旁边写着授权覆盖率，只讲相关，不讲因果。

朗读与语音输入

语音输入由你的浏览器做识别，通常是在浏览器厂商的服务器上完成——也就是说，你说的话会离开你的设备。它不经过我们，我们也拿不到。朗读默认用浏览器自带的音色。两者浏览器都不支持时，它直说，并给出线下那条路。

大白话 · 大字号

不是前端改写。走的是智能体自己那条无障碍设置的路，所以下一句回答本身就变了。

中文 / English

界面和回答都能切。切换影响的是下一句回答，不是下一个会话。

查不了，就说查不了

语料没覆盖、检索没配置，它会说这是「查不了」，不是「没有」，并给出官方入口和 12333。

06阿桥 是谁

一个对谁都没有权力的名字

桥，是这个产品自己的比喻。单字前面加「阿」，是叫熟人的叫法，不是叫官方的叫法——这就是设计上的决定：这套系统对谁都没有权力。它不判定资格，不给人打分，它说清楚谁说了算。叫「顾问」会宣称一种它没有的身份，而它面对的人，往往一听到官腔就想到自己办不完的手续。

语气跟着这个来：话短，冷静，从不安慰。不说「别担心」。不知道就直说一次。它把你当成一个能自己做事的人。也正因为温情最容易磨掉一句诚实的「不行」，这个人设配的是一道检查而不是一个愿望：说了没有事实撑着的宽心话，就会被拦下。

头像是一座读起来像脸的桥：桥面上两盏灯是眼睛，下面的拱是嘴。四种表情，真正重要的是那张严肃的脸——被拦下或被拒绝的时候，拱会拉平。一个在说「我把那句话拦下来了」的时候还在笑的界面，正是这个人设在文字上禁止的事。

07真话

这个版本做不到的事

一个禁止自己说宽心话的产品，首页也不该说。

语料是虚构的

这里的岗位、培训、创业扶持、补贴和办事指南全部是我们编的，形状照着真的做，好让整条链路能端到端跑通。每条记录的依据编号以 SAMPLE/ 开头，对话界面上「演示语料」这个标记一直亮着。接入真实数据源前，请勿据此办事。

「提交」没有对接受理系统

它记录并跟踪这次申报，同时明说你还得自己走一遍它展示出来的渠道。一个假装已经替你提交了的演示，比一个承认做不到的更糟。

方言只在文字里

它会用你说的那种话回你——粤语就写粤语口语，四川话就写四川话，不是普通话加几个语气词。但读给我听没有方言音色，那些字会被念成普通话音。写得好不好因方言而异，写不好它会直说并换回大白话普通话，不硬凑。办事的名称、编号、电话、地址一律保持官方写法——那是你到窗口要说、要往表格里填的东西。

全国实时检索要单独配置

这项检索要单独配上一个搜索服务的 key。没配的时候，语料库没覆盖的城市只能给到官方入口和 12333，给不出具体的用人单位或课程。那是「查不了」，不是「没有」——界面上会这样写。

现在就问它一句

用你自己的话说清处境就够了：在哪个城市，会点什么，卡在哪一步。
